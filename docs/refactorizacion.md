# Plan de Refactorización (`scc --by-file`)

Inventario completo generado a partir de `scc --by-file` sobre las dos áreas definidas para la refactorización:

1. `personal-app/src/`
2. `backend/`

## Criterios para `¿Se refactoriza?` (`true` / `false`)

- **Frontend (`personal-app/src/`)**: máximo **400 líneas de código** por archivo. Se marcan en `true` todos los archivos que superan las `400` líneas de código (y al refactorizarlos, ningún archivo resultante debe exceder ese límite); el resto queda en `false`.
- **Backend (`backend/`)**: se marcan en `true` los archivos de producción con tamaño monolítico (`>= 250` líneas de código) o complejidad ciclomática elevada (`>= 25`), más el spec acoplado al extractor gigante (`book-reading.extractor.spec.ts`). Quedan en `false` la documentación (`README.md`), configuraciones JSON/YAML y suites de tests estándar.
